# Minecraft Roguelike Mod

Transform Minecraft into a true roguelike experience with dynamic skill trees, RPG-style items, unique character classes, and brand-new gameplay mechanics that enhance progression and challenge.

## Features

- **Skill Tree System** – Unlock and customize abilities to suit your playstyle.
- **RPG Items** – Discover powerful gear with unique attributes and effects.
- **Character Classes** – Choose from different classes, each with distinct strengths and abilities.
- **New Gameplay Mechanics** – Experience a fresh take on Minecraft with revamped progression and combat.

## Installation

1. **Download & Install Minecraft** – Ensure you have the correct version.
2. **Install Fabric** – The mod requires Fabric as the mod loader.
3. **Download the Mod** – Get the latest release from the [Releases](https://github.com/yourusername/minecraft-roguelike/releases) section.
4. **Move the File** – Place the downloaded `.jar` file into the `mods` folder in your Minecraft directory.
5. **Launch & Play** – Start Minecraft and enjoy the roguelike adventure!
